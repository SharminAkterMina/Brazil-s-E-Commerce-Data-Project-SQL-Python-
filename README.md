# Brazil-s-E-Commerce-Data-Project-SQL-Python-
A data analytics Project

I have collected the Dataset of Telco based Customer Churn Prediction project from Kaggle. The Dataset link is given below:
https://www.kaggle.com/datasets/ujjwalinsights/target-case-study-using-sql

Then I analysis the dataset and try to find some result of analysis

The questions I tried to find answer after analysis:
1. Find the total sales per category. (use of multi JOIN)
2. Calculate the percentage of orders that were paid in installments.
3. Count the number of customers from each state.
4. Calculate the number of orders per month in 2018.
5. Find the average number of products per order, grouped by customer city.
6. Calculate the percentage of total revenue contributed by each product category.
7. Identify the correlation between product price and the number of times a product has been purchase
8. Calculate the total revenue generated by each seller, and rank them by revenue.
9. Calculate the moving average of order values for each customer over their order history.
10. Calculate the cumulative sales per month for each year.
11. Calculate the year-over-year growth rate of total sales.
12. Identify the top 3 customers who spent the most money in each year.
13. List all unique cities where customers are located.
14. Count the number of orders placed in 2017.
